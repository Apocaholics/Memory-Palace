# Намір: тренажер палацу пам'яті на колоді карт

Статус: підтверджено користувачем 2026-10-24.

## Результат

Веб-тренажер для техніки палацу пам'яті на одній колоді карт. Запам'ятовування відбувається на фізичній колоді, руками. Сайт видає випадковий порядок і потім виступає суддею: перевіряє, чи правильно відтворено послідовність.

## Користувач

Автор сам, для власного тренування.

## Ітерація 1 (поточна)

1. **Генерація.** Випадковий порядок 52 карт, без джокерів.
2. **Розкладка.** Сайт показує карти по одній, крок за кроком, а користувач складає фізичну колоду в тій самій послідовності.
3. **Запам'ятовування.** Користувач гортає фізичну колоду. Сайт на цьому етапі не потрібен.
4. **Перевірка.** Користувач записує колоду з пам'яті на папері. Сайт показує карти по черзі, одразу лицем, не показуючи наступних (уточнено 2026-10-25: без окремої кнопки «Відкрити»). На кожній відкритій карті користувач ставить ✓ (збіглося) або ✗ (помилка).
5. **Підсумок.** Рахунок (наприклад, «47/52») і номери позицій з помилками.

**Успіх:** можна пройти повний цикл від генерації до підсумку з помилками, не підглядаючи наперед.

## Ітерація 2

- Два таймери: перший на гортання з запам'ятовуванням, другий на виписування з пам'яті.
- Історія спроб: дата, рахунок, позиції помилок, обидва часи. Мета: бачити прогрес у швидкості запам'ятовування.

## Ітерація 3

- Надійне зберігання статистики, яке не зникає після очищення кешу браузера (сервер, хмара тощо; вирішити пізніше).

## Обмеження

- Простий застосунок, без зайвого.
- Використання з ноутбука або телефона, що лежить поруч на столі. Інтерфейс має бути зручним на обох.

## Поза межами

- Акаунти й логін.
- Кілька колод (формат змагань).
- Інші мнемотехніки (числа, імена тощо).
- Введення відповіді на сайті замість паперу.
- Мультиплеєр.
